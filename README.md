# Roleta de Sorteio (Viciada/Animada)

Uma aplicação simples em HTML, CSS e JavaScript para realizar sorteios usando uma roleta animada.

## Funcionalidades
*   **Adicione múltiplas opções**: Coloque os nomes ou itens no campo de texto (um por linha).
*   **Resultado Desejado (Opcional)**: Se quiser que a roleta pare em um item específico, basta digitar o nome no campo "Resultado Desejado".
*   **100% Animada**: A roleta gira fluidamente usando `requestAnimationFrame` com aceleração e desaceleração (ease-out).
*   **Design Responsivo**: Usa Tailwind CSS para um design limpo e adaptável a telas menores.

## Como usar
Basta abrir o arquivo `index.html` em qualquer navegador web moderno. Não é necessário nenhum servidor de desenvolvimento ou build.

## Publicando no GitHub
1. Abra o terminal nesta pasta (`roleta-da-sorte`).
2. Execute `git init`
3. Execute `git add .`
4. Execute `git commit -m "Initial commit: Roleta animada"`
5. Use o GitHub CLI: `gh repo create roleta-da-sorte --public --source=. --remote=origin --push`
